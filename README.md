# Business Insights 360 – Power BI Dashboard

## Project Overview

This project is a comprehensive Power BI dashboard developed to analyze and visualize key performance metrics across various departments at AtliQ Hardware. It provides actionable insights into finance, sales, marketing, supply chain, and executive operations, empowering stakeholders to make informed decisions for strategic growth.

## Dashboard Views

- **Home Page –** Project details and context.
- **Finance View –** Analyze Gross/Net sales, margins, and profitability analysis.
- **Sales View –** Gain insights into customer and product performance metrics.
- **Marketing View –** Evaluate marketing performance and profitability across relevant segments.
- **Supply Chain View –** Monitor forecast accuracy, inventory-related insights.
- **Executive View –** Provide a consolidated overview of important business KPIs to support strategic decision-making.

## Data Sources

The dashboard gathers data from two primary sources:

- **Excel/CSV Files:** Targets and operating expenses data, along with related information, are collected from Excel and CSV files.
- **MySQL Database:** Essential facts and dimensions for all departments are pulled from a MySQL database.
